# AI Tutorial for University Researchers

A self-study tutorial (website + runnable notebooks) that takes university researchers outside AI/CS from basic AI concepts to using AI in their own research. The running case study is bearing fault diagnosis from vibration signals.

## Layout

- `book/` - tutorial content (Jupyter Book root). Prose is Chinese; code is English.
- `requirements.txt` - pinned dependencies for running the notebooks locally.
- `requirements-build.txt` - tools for building the site.
